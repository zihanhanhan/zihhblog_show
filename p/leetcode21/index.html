LeetCode21.合并两个有序链表

将两个升序链表合并为一个新的 升序 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode total = new ListNode(-1);
        ListNode ans = total;
        while(list1 != null && list2 != null){
            if(list1.val <= list2.val){
                ans.next = list1;
                list1 = list1.next;
            }
            else{
                ans.next = list2;
                list2 = list2.next;
            } 
            ans = ans.next;
        }
        if(list1 == null)
            ans.next = list2;
        else
            ans.next = list1;
        return total.next;
    }
}

整体逻辑非常简单，只需要先创建一个新链表，包含一个虚拟头结点，方便处理空指针问题，然后while循环找到list1和list2的结点值哪个更小，小的接在ans后，之后一直比较直到有一个链表指针指向空，再把剩下的一条链表直接接在ans后即可

针对这道简单的题其实我更想说的知识点是什么时候需要把原链表之间的链断开，什么时候不需要断开，这个要和下一道题一起来分析

Leetcode86.分隔链表

给你一个链表的头节点 head 和一个特定值 x ，请你对链表进行分隔，使得所有 小于 x 的节点都出现在 大于或等于 x 的节点之前。

你应当 保留 两个分区中每个节点的初始相对位置。

class Solution {
    public ListNode partition(ListNode head, int x) {
        ListNode small = new ListNode(-1);
        ListNode big = new ListNode(-1);
        ListNode p1 = small, p2 = big;
        while(head != null){
            if(head.val < x){
                p1.next = head;
                p1 = p1.next;
            }
            else{
                p2.next = head;
                p2 = p2.next;
            }
            ListNode temp = head.next;
            head.next = null;
            head = temp;
        }
        p1.next = big.next;
        return small.next;
    }
}

这个题要创建两条链，一条链的值比x小，另一条比x大，最后再把这两条链拼接起来

这道题需要断开原来的链，但是第21题不需要，因为

合并两个有序链表（mergeTwoLists）

👉 操作的是 两条链表：

  • 从 l1 和 l2 中取节点
  • 拼接成第三条新链表
  • 原来的 l1、l2 就算没断，也不会影响拼好的链表结构
  • 因为是“顺着两个链走一遍”

分隔链表（partition）

👉 操作的是 一条链表：

  • 要把这一条链**“拆成两条”**：小的和大的
  • 然后再拼回去
  • 如果不手动断开，同一个节点的 .next 会指向原链的后续部分
  • 那新拼的链尾巴就不干净了，会出错，甚至形成环（死循环）

“合并”是从两条链中选；“分割”是从一条链里拆！拆的时候必须断开，选的时候不需要。”
